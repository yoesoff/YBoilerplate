Project Description

This project is a Spring Boot application with a simple greeting feature and RESTful endpoints.

Available Endpoints
  • /greeting - HTML greeting page
  • /rest/greeting - RESTful greeting endpoint
Actuator Endpoints
  • /actuator/health - Health check endpoint
  • /actuator/info - Application info endpoint
